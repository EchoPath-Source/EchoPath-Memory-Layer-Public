# Public / Private Boundary

## Purpose

This document clarifies what this public repo is for and what remains controlled by EchoPath XR.

---

## Public Repo Includes

This repository includes:

- public documentation
- API contract
- quick-start guide
- integration guide
- Unity / Godot / Web adapter examples
- browser demo scaffolds
- build-your-own explanation

This repo teaches the pattern.

---

## Public Repo Does Not Include

This repository does not include:

- full production runtime
- paid plugin source
- private optimized kernel logic
- EchoPath Neuro research prototypes
- Collapse Neural Network v7+ models
- Q-RRG convergence internals
- future EchoPath Cognition / Native / Director internals
- partner builds

---

## Distribution Model

```text
Public repo = examples + docs + demos
Website = product funnel + downloads + support
Private repo = runtime + research + plugin builds
```

---

## Why This Boundary Exists

The public repo helps developers trust and understand the product.

The private layer protects:

- development investment
- product roadmap
- research advantage
- commercial plugin value
- partner-specific implementation work

---

## Recommended Public Wording

```text
The public repository includes examples and documentation.
The full runtime is distributed through preset packs, plugin downloads, and private partner builds.
```

---

## Anchor Statement

```text
Expose enough to prove value. Protect enough to fund development.
```
